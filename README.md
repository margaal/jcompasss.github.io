# jcompasss

Projet personnel en cours de développement.

jcompass est un outil d'aide à l'orientation destiné aux jeunes (alternance, stage, premier emploi). Il donne des repères sur les débouchés des formations et sur le marché de l'emploi, à partir de données publiques.

- Usage strictement non commercial
- Statistiques agrégées uniquement, aucune revente de données
- Les sources de chaque chiffre sont citées
